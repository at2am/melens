## Deliberate interface choices

Operational request envelope [144,-39,146.5,-37] is not source coverage. Dynamic UTC windows are ≤31 days; source statistical date-only period bounds are explicit and may be longer. Catalog/viewport/item/list envelope names match MapLayerCatalog/ViewportResponse/MapItemResponse/MapItemPage; GET unlocated sends one URL-encoded JSON query parameter. item.kind selects details without runtimeType.

Cursor tokens are opaque through an injectable server-side resolver. Snapshot holds normalized context, original selectedLayers, source-version watermark and five-minute expiry; continuation requests have exactly one bound layer and snapshotId. All source access is rechecked per successful read. No new signing-key infrastructure or persistent cache required.
