## Frozen integration API

`selectionControllerProvider` retains a `MapSelectionState` for the application session. It exposes `selectedItemId`, `item`, `context`, `mode`, `dataMode`, `disposition`, `aggregateId`, `isLoading`, `detailError`, `hasSelection`, `highlightedItemId`, `highlightedAggregateId` and `canRetry`.

The notifier has:

- `Future<void> selectItem(MapItem item, {required MapReadContext context, required MapQueryMode mode, required MapDataMode dataMode})`
- `void clear()`
- `Future<void> retryDetails()`
- `void reconcile({required Set<MapLayerId> enabledLayers, required Iterable<MapItem> visibleItems, bool matchesFilters = true, Set<String> removedIds = const {}, Set<String> withdrawnIds = const {}})`
- `void setAggregateMembership(String? aggregateId)`

A caller must supply `matchesFilters` from the original selected request versus current time/filter context. An absent item in a viewport only establishes `offscreen`; it never establishes deletion. Explicit removal/withdrawal evidence clears content and highlight. Filter exclusion clears highlight while retaining original facts. A null-geometry selection remains a scoped record without a geographic highlight or an inferred offscreen location.

T024 can call `setAggregateMembership` only after membership is evidenced. It links a current aggregate highlight while preserving original individual details. Reconciliation clears old aggregate linkage; callers then attach evidence from the current result. Aggregate ids are never derived from proximity or opaque-token decoding.

`MapDetails({required MapSelectionState state, required VoidCallback onClose, VoidCallback? onRetry, ValueChanged<Uri>? onOpenSource, Widget? additionalContent, Widget? Function(MapItem item)? typedDetailsBuilder})` renders a bounded scrolling panel. `typedDetailsBuilder` can replace the generic typed facts for T018/T024; returning null uses the built-in typed facts. Common provenance appears once after the typed section.

`MapDetailsLayout({required Widget map, Widget? details})` uses a 360-pixel side panel at widths >=720 and a bottom panel capped at 360 pixels / 48% height on narrower layouts. Both require bounded parent constraints.

`UnlocatedList({required UnlocatedQuery query, required ValueChanged<UnlocatedSelection> onItemSelected, String? selectedItemId, VoidCallback? onClose, ValueChanged<Uri>? onOpenSource})` owns its cancellable request and replaces one bounded page at a time. The caller supplies approved scope evidence. `UnlocatedSelection` exposes `item`, `context`, `mode`, `dataMode`; its detail context uses the returned unlocated snapshot, not a viewport token.

## Behavior and safeguards

Details read through `MapRepository.getItem` with the selected snapshot. Responses must match request id, snapshot id, stable item id, version id, mode and data mode. Superseded success/errors and disposed work are ignored/cancelled. Network failure retains original facts with their original dates and offers manual retry against the same snapshot. Snapshot expiry explains that the user must select from refreshed map data; it never silently requests a new snapshot. notFound/notAvailable removes public selected content. Explicitly withdrawn DTOs are never requested or displayed.

Typed pedestrian details use `MapMeasuredCount`, keep null directions/counts unknown and measured zero exact, show minute/hour granularity, source-channel direction limitations, observation window and location validity. Transport/event/planning/boundary fields retain their source statuses, extent, unknown times, permit ids and boundary vintage. Common source/time/sample/prediction presentation uses `MapItemProvenance`. Original area/line/point/unlocated precision and evidence remain explicit. Additional registered DTO kinds have basic typed facts without activating later feature workflows.

Public HTTP(S) links use the parent's `onOpenSource` callback; without an opener their URLs are selectable. No URL-launcher dependency was added. Close controls have accessible labels; Escape closes focused panels. Unlocated rows support keyboard traversal and Enter activation.

The list displays the exact supplied area references or jurisdiction and explicitly disclaims viewport membership. Empty pages are page-level statements; unknown exact totals remain unknown. Partial pages remain partial. Pagination uses the opaque returned cursor and snapshot; expiry offers an explicit restart that clears the old page before a new query. Query changes cancel old work and suppress late results. Scrollable metadata plus a virtualized list prevent overflow in short narrow constraints.
