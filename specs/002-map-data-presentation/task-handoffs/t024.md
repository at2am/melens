`SelectionController.reconcile` keeps its existing signature. It prefers a directly visible original record; otherwise, a current non-withdrawn aggregate in the same layer whose supplied `memberIds` includes the selected original establishes its containing aggregate. The original item, version, source geometry, and read snapshot remain unchanged. A group is never inferred from bounds, loaded counts, or absent membership evidence. T016's scoped null-geometry selections keep their existing matching disposition without an inferred offscreen location.

`highlightedItemId` remains the original ID. T023's `aggregateRepresentsSelection` uses it to highlight the containing group. `highlightedAggregateId` identifies that group for the detail notice. Filter exclusion clears both map highlights and retains original details; explicit removal or withdrawal clears content and cannot be reversed merely by a new group response. Missing viewport membership remains offscreen and retains the source location.

The embedded aggregate member panel requires a Material ancestor inside the detail background. The integration test reproduced Material UI's assertion when member ListTiles were placed beneath the existing opaque DecoratedBox. The wrapper now uses an equivalent bordered Material surface, preserving visible keyboard focus and list ink. The selected aggregate explanation is also a semantic live region.

## Integration contract

- Call `reconcile` with current viewport items and actual filter eligibility. No follow-up aggregate-membership loop is needed; such a loop can overwrite direct-record precedence or accept a withdrawn or unrelated group.
- After selecting an aggregate member, reconcile it against the current response immediately so the group highlight does not depend on a later camera request.
- Keep the original ID in MapSurface's `selectedItemId`. Keep the original snapshot/version for item reads; a new viewport response must not replace detail data.
- `setAggregateMembership` remains source-compatible for existing callers with explicit membership evidence.
