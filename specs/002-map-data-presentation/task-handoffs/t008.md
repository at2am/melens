# T008: Map repository interface and HTTP adapter

**Date**: 2026-10-01
**Status**: Implemented and validated against the generated T005 models. Live endpoint deployment and viewport integration remain later tasks.

## Changes

- Added a shared `MapRepository` interface covering catalog, viewport, item detail, explicitly scoped unlocated lists and aggregate members. T005's sample repository implements the same interface.
- Added `HttpMapRepository` using the injected app HTTP client. It does not close that shared client or substitute samples after an HTTP failure. Its default expected response mode is `live`; a local sample HTTP server requires an explicit `sample` mode.
- Request preflight uses T005's typed validators and validated constructors. Responses require integer `schemaVersion=1`, matching data mode and request/snapshot context. Item ids, requested layer ids and member/list scope remain bound to their requests.
- JSON DTO decoding preserves geometry, UTC instants, unknown source clock text, null counts and all coverage/freshness/completeness fields. Invalid geometry or unsupported response shapes become safe contract errors.
- URL path segments and query parameters are encoded through `Uri`; item ids cannot insert routes, fragments or query parameters. Detail and member reads use frozen snapshot context; unlocated reads carry the frozen URL-encoded JSON query.
- Bounded request JSON to 256 KiB and decoded response bytes to 2 MiB. A configurable 30-second default deadline and per-request cancellation handle support manual cancellation and future newest-request protection without adding a viewport controller.
- Added typed request, contract, service HTTP, network, timeout and cancellation errors. Exception text never includes response bodies, endpoint URLs, credentials or client exception messages. Redirects are disabled and retries remain caller-controlled.

## Integration handoff

- Construct the adapter with `HttpMapRepository(client: client, baseUrl: env.mapBaseUrl, expectedDataMode: env.mapDataMode)` from the T009 provider. A repository has no disposal method because the existing HTTP provider owns its client.
- Use one `MapRequestCancellation` per operation. `cancel()` is idempotent; cancellation throws `MapRequestCancelled`. Future viewport state should cancel superseded work and retain its request-id guard.
- `MapHttpException.code` retains the recognized v1 service error enum, including `snapshotExpired`, while `retryable` supports explicit UI retry. UI messages come from English localization, not server bodies.
- The frozen contract specifies the 256 KiB JSON limit and no separate practical GET URL ceiling. This implementation applies that byte limit to unlocated query JSON before URL encoding. Deployment/proxy URL limits must be recorded before accepting large live unlocated-list filters; no undocumented URL cutoff was introduced here.
