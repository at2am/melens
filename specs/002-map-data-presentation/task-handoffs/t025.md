The frozen v1 wire has `zoom` and no `zoomBand`. `ZoomPresentation` maps the active band to a supported nominal-band zoom: overview10, district12, neighbourhood15, closeUp18, matching T022's server scales. `ViewportState.zoom` and its bounded actual visible region remain real. `zoomPresentation` captures the latest idle camera and its 0.2 hysteretic band; `responsePresentation` captures the camera/band used by the retained successful response. `responseQuery.zoom` is the presentation zoom and remains the exact snapshot continuation context. A service-scope catalog fallback does not establish hysteresis before the first real camera is classified nominally.

Crossing a boundary by only0.1 never changes request granularity or group membership. Superseded completions and failures cannot replace a newer response/presentation context. Failed refreshes retain the original response/query/presentation. T017's cameraMoving/isCameraMoving/awaiting-region cancellation and selected original time/filter checks remain intact.

The viewport service applies one aggregation hook to every loaded layer, including trusted injected loaders. Production `createMapService` defaults to T022 `aggregateLayer`; tests may inject a presentation hook explicitly. Actual original identities, including supplied pre-grouped members, must fit the assigned per-layer share of the global1000-row budget before grouping. Invalid/excess aggregation returns a bounded service/budget error. Layer coverage, unresolved counts, completeness and original query totals are preserved; presentation counts do not become city-wide source totals.

The query runner's original-row and UTF-8 result-byte limits remain active; final envelope limits remain1000 presentation items and2MiB uncompressed. Grouping a partial buffer into fewer symbols never restores a complete total or creates a continuation into unloaded rows. Aggregate resultRange and member pages preserve actual loaded scope with unknown full totals. Snapshot detail/member routes still use stored original ids/versions/geometry and T014 current source/record public-eligibility checks.

Map rendering receives the original selected ID. T024 derives linked membership from current same-layer, non-withdrawn member evidence without replacing source details. The obsolete caller membership loop is removed. Choosing a listed member reconciles it immediately against the current response. Clicking an aggregate fits its supplied real-member bounds; dense close-up groups retain the accessible member list, provenance, window/unit and loaded-scope notices.

An explicit expired-member refresh rebinds only a still-selected matching aggregate found in a successful new snapshot with current time/filters. A changed selection, failed refresh, pending motion, missing group or stale context keeps the old explicit state. Ordinary selected details never silently switch snapshots. `AnomalyDetailsSection` is connected through MapDetails. No producer, detector or product fixture was introduced; unavailable producer/public-rights gates remain unchanged.
