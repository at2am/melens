## Frozen interfaces

`PublicSourceCoverage` contains effective license/access admission, source id/topic/scope, public coverage references, declared coverage bounds, health, published batch/instant/window/output count and coverage evidence state. `SourceCoverageSnapshot` contains these sources and `completeness=complete|partial`.

- `parseSourceCoverage(ViewQueryResult)` validates the BigQuery boundary, discards unknown/private fields and returns safe `MapQueryError` on malformed or duplicate metadata.
- `createSourceCoverageReader({runner}).read(request, execution?)` uses the existing fixed query runner and approved view. It requests up to 1,000 source rows independent of the client page size and rechecks current public access independently of stored cursor/snapshot tokens. A lower configured runner limit still applies and produces partial source evidence.
- `findPublicSource(snapshot, sourceId)` returns a source only when its effective license/access is admitted and its publication has a batch and timestamp. Denied, missing and unpublished sources return null. Published zero output remains a valid publication.
- `sourceBelongsToLayer(source, layerId)` maps data topics to registered layers. Pedestrian-location and static-transit/activity-count reference sources do not advertise observation/disruption layers; rent/census match the fixed source-specific queries.
- `assessLayerCoverage({snapshot,layerId,request?,resolveArea?})` returns coverage, freshness, availability, source ids and update time. `resolveArea(source,bbox)` returns `contains|disjoint|unknown` from actual public boundary evidence. No scope string, operational service envelope or manifest name supplies containment proof.
- `finalizeLayerResult({layerId,assessment,items,completeness,unresolvedCount,totalMatching,nextCursor?,observedWindow?,querySucceeded?})` supplies the shared empty-result policy. A failed query yields unavailable with no exact total. Empty queries remain unknown unless request-specific evidence proves coverage, the query completed successfully, the exact total and unresolved count are both zero, and no cursor remains.
- `createLayerCatalogService({readCoverage,clock?}).getCatalog(execution?)` produces the exact nine frozen v1 descriptors in live mode. Missing anomaly producer is unavailable. A complete admitted registry with no relevant source is notCovered; partial registry absence is unknown. Catalog availability never claims noMatching.

`LayerCoverageAssessment.queryCoverageVerified` is optional and is true only for a request-specific assessment with spatial/time proof. `finalizeLayerResult` requires it for noMatching. Generic catalog coverage cannot establish an empty-query conclusion. The optional `clock` returns a Date for deterministic tests.

SourceReference uses the shared contract type. Record adapters supply validated public record links and attribution; this module invents neither provider URLs nor source metadata for missing sources. T014 must also use current public-source checks when serving stored snapshots/details.

## Coverage and freshness limits

Query coverage requires all relevant admitted sources to have healthy publication and verified area references, explicit bbox containment and a published window containing the request window. Declared coverage and the latest successful published window are intersected with microsecond precision. Partial source results, mixed faults, unknown area evidence, missing windows and tiny temporal gaps cannot prove noMatching. Stale published data can remain readable while its freshness is stale and its coverage proof is unknown.

Versioned planning/boundary snapshots may expose verified source-area evidence with `coverage.window=null`. That does not prove continuous dynamic time coverage. Current geo queries also exclude unlocated facts, so adapters must leave unresolvedCount null until a separate approved area/jurisdiction read establishes the exact relevant count. Empty spatial rows alone never establish unresolvedCount=0.

No boundary resolver is fabricated in this task. T014 can supply one only when it has actual boundary containment evidence; otherwise query-empty stays unknown. The global source summary is intentionally more conservative than an inferred continuous history: the latest published window is not silently extended backwards or forwards.
