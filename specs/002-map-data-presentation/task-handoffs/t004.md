## Read-only environment requirements

Health development and injected-adapter tests need no Google credentials. Real queries need `MAP_PROJECT_ID`, the T007 query configuration and ADC under the dedicated development query identity. That identity needs query job creation and read access to only reviewed authorized `melens_query` views. It receives no ingestion writes, direct raw/staging access or source-secret access.

The local entrypoint does not prove query IAM, source publication, map API readiness, CORS/public origin policy, Cloud Run deployment or product acceptance. Those have separate owners and evidence gates.
