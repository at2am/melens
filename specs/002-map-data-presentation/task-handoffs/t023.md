## Frozen integration API

`buildAggregateRenderPlan(context, items, selectedItemId, onSelected, {icons, onZoomToBounds})` returns T015's public `CoreRenderPlan`. Its first four arguments match MapSurface's synchronous aggregate-renderer hook. It skips null/invalid geometry and the later coverageGrid representation.

`AggregateRenderLayer(items:, selectedItemId:, onZoomToBounds:, builder:)` creates public PNG count symbols asynchronously and gives its builder a synchronous `AggregateRenderBuilder`. Wrap MapSurface with this layer and pass the returned renderer to `aggregateRenderer`. The host requires no advanced-marker Map ID, private plugin handle or platform map for symbol generation. Its 128 distinct-symbol limit, pixel ratio cap, stale-generation guard and disposed pictures/images bound raster work. A failed/pending/over-limit raster retains the public marker and truthful count/unit in its info window and details.

`aggregateRepresentsSelection(item, selectedId)` accepts the aggregate's ID or an actual supplied `memberIds` entry. T024 can retain an individual selection while its enclosing cluster is highlighted; unknown membership is never inferred.

`AggregateDetailsPanel` takes required `aggregate`, `repository`, `readContext`, `mode`, `dataMode`; optional `onZoomToBounds`, `onItemSelected`, `onOpenSource`, `onRefreshSnapshot`, `pageSize=25`, `maxDisplayedMembers=100`. UI page size is at most 50 and displayed members at most 200. T016's `additionalContent` slot can host the panel.

Use one camera path: either the renderer host's `onZoomToBounds` or the screen's aggregate-selection handler. Wiring both handlers to a camera move would duplicate the move. The panel's explicit zoom action is independent and forwards the original supplied `MapBounds` object.

## Data semantics

The count badge and header use `ResultRange.returnedCount`: actual loaded member records. The producer's metric value/unit/definition appears separately, so distinct sensors and passage sums do not become unique people. Unknown/excluded totals receive a readable loaded-scope warning and `*` symbol. Explicit exact totals stay group-scoped. The panel preserves the observation window in Australia/Melbourne, source provenance, sample/historical/prediction labels, and individual measured zero/null counts.

For Point/MultiPoint groups, the navigation symbol anchors to the supplied Point or first stable original MultiPoint coordinate. No centroid, density field or rectangle is invented. Non-point cluster geometry uses T015's intact public geometry renderer. Bounds are navigation metadata only; T022 preserves exact member coordinates and provides minimal padding solely for degenerate navigation axes. Dense/same-location groups keep their member-list access at close zoom.

Member requests use `MapRepository.getAggregateMembers` and the viewport snapshot. The panel independently guards schema/request/snapshot/mode/dataMode/group scope, response page size, exact-total consistency, stable member version, and cursor progress. It deduplicates identical member IDs/versions, rejects conflicting versions or repeated cursors, stops at row/page limits, preserves earlier rows on a retryable failure, cancels superseded/disposed requests and ignores late replies. Expired snapshots offer a viewport-refresh callback rather than retrying the expired cursor. The list never invents an exact total from retrieved rows or claims empty coverage.
