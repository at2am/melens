# 行人计数的位置时间核查

本次基线是主线 `3ce8804`。该版主线仍只检查计数起点是否位于传感器位置的有效期。它也只比较具有相同起始时间的位置版本。这会产生两个错误：把移动前的位置用于跨越移动时间的整小时计数，以及忽略有效期重叠但起始时间不同的冲突位置。

本次修复要求单个位置覆盖完整计数区间。分钟区间为 `[observed_at, observed_at + 1 minute)`，小时区间为 `[observed_at, observed_at + 1 hour)`。如果计数区间跨越位置移动时间，则保留计数并返回 `unlocated`。如果存在覆盖完整区间的位置，代码还会检查所有相交位置的几何和设备状态。相交证据冲突时返回 `ambiguous`。

在有效期终点恰好结束的计数可以使用旧位置。在新位置有效期起点开始的计数可以使用新位置。没有完整位置覆盖时不生成坐标。缺失计数仍为 null。设备停用规则保持有效。
