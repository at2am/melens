## 3. 官方上游只读核查证据 (Bounded & Read-Only)

核查执行时间：2026-09-30 12:27 - 12:30 UTC

### 3.1 数据集元数据与几何类型
- **Metadata API URL**: `https://data.melbourne.vic.gov.au/api/explore/v2.1/catalog/datasets/on-street-parking-bays`
- **HTTP 响应**: `200 OK` (Server: openresty, Content-Type: application/json)
- **总记录数**: `29,053`
- **官方字段定义**:
  - `roadsegmentid` (int)
  - `kerbsideid` (text)
  - `roadsegmentdescription` (text)
  - `latitude` (double)
  - `longitude` (double)
  - `lastupdated` (date)
  - `location` (geo_point_2d)
- **官方几何属性**:
  - `geometry_types: ["Point"]`：官方元数据明确指定几何类型为单一 `Point`，并非 Polygon。
  - 数据集文字描述虽提及 "This dataset contains spatial polygons which represent parking bays across the city"，但**底层字段与导出的实际几何完全为点 (Point)**，无任何多边形边界或顶点序列。连接器严格遵守点几何，绝不进行虚构车位多边形外扩。
  - Bounding Box 范围：`[144.90058, -37.85054]` 至 `[144.99063, -37.77563]`，全量车位均落在墨尔本市 WGS84 合法经纬度范围内。

### 3.2 坐标核查与空值检验
- `latitude is null` 查询结果：`0` 条
- `longitude is null` 查询结果：`0` 条
- `latitude = 0 or longitude = 0` 查询结果：`0` 条
- 坐标全局重复度检验：按 `(latitude, longitude)` 分组统计，最大计数值为 `1`。即 29,053 个车位坐标点在空间上完全互异。

### 3.3 KerbsideID 关键事实核查
- **空值分布**：
  - `kerbsideid is not null`: **5,072 条 (17.46%)**
  - `kerbsideid is null`: **23,981 条 (82.54%)**
  - 结论：**绝大多数车位无 kerbsideid**。连接器必须在 `kerbsideid == null` 时依赖坐标与路段有效生成车位记录，不可丢弃。
- **跨路段重复分配事实**：
  - 官方数据存在多组跨路段重复的 `kerbsideid`（计数值均为 2），例如：
    - `kerbsideid = "17212"`：
      - `roadsegmentid: 20472` (Berkeley Street between Queensberry St and Pelham St, lat: -37.8038058, lon: 144.9594192)
      - `roadsegmentid: 22630` (Wellington Parade South between Wellington Cres and Flinders St, lat: -37.8160071, lon: 144.9753201)
    - `kerbsideid = "23856"`：
      - `roadsegmentid: 22452` (Harbour Esplanade, lat: -37.8164399, lon: 144.9456987)
      - `roadsegmentid: 21514` (Jeffcott Street, lat: -37.8118126, lon: 144.9521476)
  - 结论：**`kerbsideid` 绝不能单独作为主键**。连接器以 `roadsegmentid:kerbsideId:lat:lon` 作为复合 `nativeId`，确保两个车位均能正确保存，不发生碰撞覆盖。

### 3.4 Marker_ID 上游缺失事实
- 针对官方 API 执行 `where=marker_id is not null`：
  - 返回错误：`ODSQLError: Unknown field: marker_id`
- 针对官方 API 执行 `where=markerid is not null`：
  - 返回错误：`ODSQLError: Unknown field: markerid`
- 结论：官方虽然在文字描述中称传感器通过 `marker_id` 关联车位，但当前车位快照中**根本不存在 `marker_id` 字段**。连接器忠实保留 `marker_id: null`，杜绝任何人工猜测映射。

### 3.5 许可页面与免责声明状态
- **声称许可**: `CC BY 4.0` (`https://creativecommons.org/licenses/by/4.0/legalcode`)
- **官方免责声明 URL**: `https://data.melbourne.vic.gov.au/stories/s/94s9-uahn`
  - HTTP 状态：`404 Not Found`
- **车位传感器升级工程说明 URL**: `https://www.melbourne.vic.gov.au/building-and-development/shaping-the-city/city-projects/Pages/parking-sensor-upgrade.aspx`
