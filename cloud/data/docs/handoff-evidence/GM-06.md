## 3. 可重复的行为验证

针对 G23 与 T033 核心领域不变量，构建了全面的行为验证：

1. **同物业同类型多行确定性聚合**：
   - 物业 100008 的 13 和 6 车位聚合为 19 车位年度私有容量。
   - 物业 100194 的 6, 3, 4, 7 车位聚合为 20 车位年度私有容量。
2. **输入重排与去重不变性**：
   - 逆序输入 `[row13, row6]` 与 `[row6, row13]` 产出的 `version_id`、`facility_id`、`parkingBay`、`geoRecord` 100% `deepEqual`。
   - 4 条记录的 24 种全排列输入均产出完全相同的输出 bundle。
   - 重复行（如抓取重试导致的相同行重复）通过规范签名去重，不会发生重复累加。
3. **实体 ID 稳定性与版本更新**：
   - 若上游容量发生修正（例如 6 修正为 7），实体标识 `facility_id` 保持稳定不变（`melbourne.offstreet_parks:2024:100008:private`），而 `version_id` 随内容哈希更新。
4. **不变量 1：仅商业停车场为公共候选**：
   - `parking_type === 'Commercial'`：`is_public_candidate = true`, `public_access = true`, `location_role = 'event_site'`。
   - `Residential` 与 `Private`：`is_public_candidate = false`, `public_access = false`, `location_role = 'sensor_site'`。
5. **不变量 2：年度普查容量绝不写成实时空位**：
   - `annual_capacity` 仅作为静态年度容量保留；
   - `is_realtime_occupancy = false`；
   - `parkingObservations` 严格返回空数组 `[]`；
   - `observed_at = null`，`time_missing_reason` 明确声明为 CLUE 年度普查而非实时观测。
6. **实盘只读全量验证 (Live Run)**：
   - 实际调用 `connector.collect({ sourceId: 'melbourne.offstreet_parks', window: { kind: 'snapshot', revision: 'latest' }, checkpoint: null, runId: 'live-test' })`：
   - 成功从官方抓取 2024 年全部 **7,185 条** 原始记录；
   - 聚合生成 **7,035 个** 唯一设施记录；
   - 0 记录冲突，0 失败，`parkingObservations` 长度为 0；
   - 物业 100008 成功聚合为 19 车位。

### 4.4 Codex Review 返工修正 (R06) 与变异断言验证

- **问题定位**：`test/connectors/com_offstreet_parks.test.ts` 中官方实测测试最初将网络请求、解析归一化与业务断言包含在同一个 `try-catch` 块中。若断言失败（如容量计算不一致或几何校验失败），会被误吞为 `t.skip('Network unavailable...')`。
- **修正措施**：
  1. 严格将 `client.fetchRecords` 网络传输层隔离在独立的 `try-catch` 块内，仅在抛出网络异常时执行 `t.skip` 并直接 `return`；
  2. 将行数断言、容量数值校验、`normalizeOffstreetRecord` 归一化、容量聚合求和断言（19 车位）、公共候选断言以及 `validateGeoRecordGeography` 地理完整性校验全部移到网络 catch 块之外。
- **变异测试验证 (Mutation Verification)**：
  - **变异注入**：将期望容量断言突变为 `assert.equal(bundle.facility.annual_capacity, 999)`；
  - **测试表现**：运行测试立即抛出 `AssertionError [ERR_ASSERTION]: Sum of 13 and 6 must be 19 (19 !== 999)`，进程以 exit code 1 失败退出（`✖ fail 1`），未被跳过掩盖；
  - **测试恢复**：恢复断言值为 19 后，测试套件重新全绿（13/13 pass）。
