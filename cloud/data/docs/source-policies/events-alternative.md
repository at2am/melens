# Events source admission and coverage

## Ticketmaster Discovery API

- The [Discovery API v2 documentation](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/) describes key authentication, 5,000 requests per day by default, 5 requests per second, zero-based paging, and a 1,000-result deep-paging boundary. The candidate connector uses a bounded event-start window and fails an oversized search instead of silently truncating it.
- The upstream search is an approximate 80 km circle around central Melbourne, restricted to Australia/Victoria. It is neither the City of Melbourne municipality nor an official Greater Melbourne boundary. The source only covers events on participating Ticketmaster platforms; it cannot certify that no local activity exists.
- The [general API terms](https://developer.ticketmaster.com/support/terms-of-use/) restrict Event Content caching to a reasonable period, require removal after a rights-holder request within 24 hours, and prohibit an app that replicates the essential Ticketmaster experience. The current BigQuery history has no source-specific deletion or retention policy. Therefore the manifest remains `review_required`/`candidate`, normalized records remain blocked from public query, and this source cannot count toward SC-001 yet.
- Before admission, define an approved retention period for each field, test source-specific deletion across GCS and BigQuery current/history views, include attribution and a direct Ticketmaster link, and have the project owner confirm the product use against the terms. A developer API key must be placed in Secret Manager; its value must not appear in the repository or chat.

## Other everyday activities

The [City of Melbourne open-data catalog](https://data.melbourne.vic.gov.au/explore/) has historic event permits and bookable venues, which are different from a current public event calendar. [DataVic's City Activities and Planned Works catalog entry](https://discover.data.vic.gov.au/dataset/city-activities-and-planned-works) describes permitted works and event bookings under CC BY, but the linked City of Melbourne dataset currently returns `404 NotFoundResource` from the official v2.1 records API (read-only recheck 2026-09-30). Its update frequency is unknown and it cannot meet the current event sample gate while unavailable. The [What’s On Melbourne](https://whatson.melbourne.vic.gov.au/) calendar may improve free and community activity coverage, but a supported ingestion API and reuse terms have not been verified. No replacement source is selected yet. The activity coverage gate remains unmet until a permitted current source reaches the sample threshold in the feature quality rules.
