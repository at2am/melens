Long-term BigQuery retention and public display rights are unproven. | Cannot select on current terms and location evidence |
| GDELT DOC discovery alongside existing GKG | [Official DOC API](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/) can search recent articles. | This is the existing GDELT source family, not an independent local publisher; live 30-day coverage was not established. | Use for investigation only; cannot count as a separate source |

Selection requires a stable public API or licensed feed, explicit rights for metadata retention and display, a documented refresh/quota policy, and article-level URL/time/location fields. If an allowed source is found, assign a canonical ID in `source-ids.md`, define its field mapping, then implement T051. Do not relabel a restricted feed as open because its endpoint responds anonymously.
