# ABS ASGS boundaries: admission evidence

Reviewed 2026-09-30 Melbourne time. The [ABS geospatial web services catalog](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs/edition-4-july-2026-june-2031/access-and-downloads/geospatial-web-services) lists the 2021 and 2026 GCCSA, state, SA2 and annual LGA ArcGIS services. The [ABS copyright statement](https://www.abs.gov.au/website-privacy-copyright-and-disclaimer) and [2021](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs/edition-3-july-2021-june-2026/access-and-downloads/digital-boundary-files) and [2026](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs/edition-4-july-2026-june-2031/access-and-downloads/digital-boundary-files) boundary download pages identify CC BY 4.0 reuse. All four 2021 ArcGIS service metadata responses explicitly contained a CC BY 4.0 copyright notice; the 2026 services identify ABS as the rights holder and are covered by the ABS publication/copyright pages. Product use must attribute the Australian Bureau of Statistics, link to the source and licence, and identify any transformation.

Live read-only probes on 2026-09-30 fetched every reported object ID once. Revision `2021` fetched 445 features in 26 pages: 443 polygons and 2 official non-spatial LGA records, which remain source facts without fabricated geometry. Revision `2026` fetched 482 features in 27 pages: 480 polygons and 2 non-spatial LGA records. The connector keeps only code, name and geometry; it retains no raw response body. Its 100-request daily limit is a **Melens operational cap**, not a published ABS quota. It allows one 2021 and one 2026 snapshot per day with headroom. Temporary load files have a one-day declared expiry and are deleted after successful publication; an independent hourly cleanup job now removes expired orphan `staging/` objects.

Revision `2026` correctly uses the 2025 LGA service because the ABS catalog has not published a 2026 LGA layer. Those LGA boundaries retain `vintage = 2025`; they must not be labelled 2026 or silently joined to 2026 GCCSA/SA2 by a supposed common vintage. The 2021 revision uses 2021 GCCSA, state, LGA and SA2 boundaries together. Source data is versioned by `scheme + code + vintage`. The deployed query view orders corrections by the exact same-batch source record's timestamp or ordinal and fails closed when multiple versions cannot be ordered. These ABS records have no trustworthy correction order, so changed geometry for an existing version still needs such evidence before a later publication.

The 2021 snapshot was published once to project `melens-510012` development BigQuery datasets on 2026-09-30. Batch `batch_bed0cb0da68f15795a738b119307a6a35b15032d` reached `published` with 445 inputs, 443 boundary outputs and 2 non-spatial records. BigQuery retains 445 source facts with `verified_open` rights; `melens_query.v_boundaries` exposes 443 non-null geographies: 1 Greater Melbourne GCCSA, 1 Victoria state, 80 LGA and 361 SA2, all vintage 2021. The verified LGA examples include Melbourne `24600`, Port Phillip `25900` and Yarra `27350`; each has positive area. `v_source_coverage` reports this source as `verified` / `healthy_versioned`. The ingest bucket had no remaining objects. This proves one development snapshot, not scheduled source updates; the independent cleanup job was tested separately.

The 2026 snapshot was also published on 2026-09-30 as batch `batch_bb51151fd33d4ead60fd72492bbe9baa203b9c7a` (482 inputs, 480 boundary outputs, 2 non-spatial LGA facts). The view contains 1 GCCSA, 1 state and 398 SA2 polygons at vintage 2026, plus 80 LGA polygons at their actual vintage 2025. All 480 have non-null geography. Across both batches this source exposes 923 boundary polygons, while the three admitted boundary sources together expose 1,527. The bucket again had no remaining objects. The source schedule remains disabled; its reviewed snapshot revision for a future manual job is now `2026`.
