ARCHITECTURAL CONFIRMATION • TWO-TIER CANONICAL MODEL VERIFIED

在本项目设计与生产部署中，原始异构数据绝不直接暴露给业务端。系统构建了严格的“基表摄入层 (melens_ingest) → 规范化事实表 → 统一只读视图 (melens_query)”三层演进模型。无论是新闻文本、地磁停车读数、交通警报还是政府人口普查，均被收敛至统一的标准时空与实体规范中。

1. 摄入与审计控制层 (melens_ingest)
data_sources 统一管理来源 ID、准入许可状态、爬取频率与配额约束
sync_batches 不可篡改的批次审计表，记录时间窗口、成功/失败与 Checkpoint
source_records 保留原生版本、版权声明（rights_status）与来源追溯 URL
2. 跨领域规范化实体层 (Normalized Facts)
geo_records (核心统一时空大表) 所有地理事件/报道/规划统一至此表：统一 topic、时间、WGS84 几何
area_indicators (统一区域统计) 人口、租金、犯罪、就业、微气候统一为 indicator_id, value, unit
boundaries (统一空间底图) 市界、ASGS 统计区、CLUE 街区统一为 scheme + code + vintage
parking / pedestrian (领域时序) 车位几何、占用时序、限制规则、行人客流规范化事实表
3. 授权对外查询视图层 (melens_query)
v_geo_records_current / history 自动合并排重，ST_GEOGFROMGEOJSON 空间衍生，仅暴露已发布批次
v_parking_current / v_parking_sensor_current 路边车位与传感器当前状态，占用与合法停车权限解耦
v_news_current / v_crime_news_current 排除撤稿更正，限制仅提及地名（mentioned_place）的虚假点位
v_area_indicators / v_boundaries 严格同版边界关联，不同年份统计区禁止跨版本静默 Join

1. 强制统一 UTC 时间戳

全库时间字段统一采用 TIMESTAMP (UTC)。展示层统一按墨尔本时区 Australia/Melbourne 转换。上游时间缺失时记录 time_missing_reason，严禁以系统抓取时间充当事件时间。

2. 强制统一 WGS84 几何拓扑

所有点位统一为经度 -180..180、纬度 -90..90，严禁颠倒。统一生成 geometry_geojson 并派生 BigQuery 原生 GEOGRAPHY 对象。严格区分点位置信度（源坐标 vs 区域推断）。

3. 事实类型与生命周期解耦

统一划分 assertion_kind（客观观测 observation、报道 report、规划 plan、预测 prediction）。预测结果派生 is_prediction 标识，撤稿与解除事件移出当前活跃视图。

4. 统一数据权限与排重治理

生产视图对底层物理表零写入权限。通过 rights_status 动态过滤版权撤销内容，基于稳定业务键（Row Number Qualifying）对重试重放的物理行实现确定性确定去重。
